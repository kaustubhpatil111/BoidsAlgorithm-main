# Boids Learning

A C++ implementation of a Boids flocking simulation built from scratch.

## Features

- Separation
- Alignment
- Cohesion
- Wander behavior
- Velocity limiting
- Acceleration limiting
- Randomized boid spawning
- Toroidal world wrapping
- SFML visualization
- Motion trails

## Technologies

- C++17
- CMake
- SFML 2.5.1

## Build

```bash
mkdir build
cd build
cmake ..
cmake --build .
